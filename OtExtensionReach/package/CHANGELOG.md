# Changelog

## Unreleased

- `DisableSpaceRequirement` now defaults to `true`, since packing upgrades
  close together is a core part of what the mod is for. Existing config
  files keep whatever value they already have.

## 1.0.0

Initial release.

- `MaxStationDistanceMultiplier` - extends how far a crafting-station upgrade
  can be placed from (and still count toward the level bonus of) its
  station.
- `DisableSpaceRequirement` - lets upgrades be placed right next to each
  other.
