# Changelog

## 1.0.0

Initial release.

- Megingjord can be upgraded at the Forge to level 8, one level per biome
  after the Black Forest.
- Each level needs an item Haldor sells once the boss opening that biome is
  defeated, plus that biome's materials.
- Carry weight grows with the belt's level, from +150 to +1,700.
- Prices, materials, carry bonuses and unlock keys are configurable.
